\# AI Finance Lab



A personal build lab focused on producing tangible projects in finance, tech, and energy.



\## Structure

\- src/        Core code

\- data/       Data files (not secrets)

\- notebooks/  Exploration

\- tests/      Tests



\## Setup (Windows)

1\) Create venv

2\) Install requirements

3\) Run scripts from src/



\## Scripts
